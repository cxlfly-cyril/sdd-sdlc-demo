# 任务清单规格

状态：已批准（2026-10-10）。版本：1.1。

## 用户与目标

单人使用浏览器管理自己的任务，刷新后仍能继续查看。

## 范围

单页面；添加、切换完成状态、删除；localStorage 存储。
不含登录、服务端、多人同步、排序、截止日期。

## 验收标准

- AC-001：输入经 trim 后非空的标题并提交，新增一条未完成任务，显示 trim 后标题，并清空输入。
- AC-002：全空白或空标题不产生任务，页面显示可理解的提示。
- AC-003：点击任务完成控件，切换该任务的完成状态；再次点击恢复未完成。
- AC-004：点击删除控件，只删除对应任务；其他任务保持不变。在支持鼠标悬停的 PC 端（宽度大于 540px），删除控件仅在任务行悬停或包含键盘焦点时显示；手机及触屏设备始终显示，并保留至少 44×44px 点击区域。
- AC-005：正常存储条件下，刷新页面后任务标题和完成状态保留，已删除任务不恢复。

## 约束

任务拥有唯一 ID；同名任务允许存在，操作按 ID 定位。标题渲染为文本。存储损坏时显示恢复提示并进入空列表；存储不可用时允许当前会话使用，并提示刷新后可能丢失。第一版覆盖这些降级行为，但不承诺恢复损坏数据。
