## 意图与规格影响

主分支要求 PR 和 Acceptance checks 通过。CI 检查结构与声明，分类合理性、证据真实性及业务语义由 Agent 和人工审阅负责。未配置云端 Agent 自动启动，也不需要 OpenAI Secret。
