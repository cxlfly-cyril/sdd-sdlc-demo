# PC 删除控件悬停显示

## 意图与规格影响

用户明确要求 PC 删除操作仅悬停时显示。更新任务规格 AC-004 到版本 1.1：鼠标设备且宽度大于 540px 时默认隐藏，任务行 hover 或 focus-within 时显示；手机、触屏保持常驻及 44×44px 触控区域。按 ID 删除及持久化行为不变。

用 opacity 隐藏并保留布局及键盘可聚焦性，隐藏状态不接收指针点击；键盘聚焦进入任务行后恢复显示。历史 Changes 保留原有事实。

## 验证

2026-10-10：33 项单元测试、类型检查通过；6 项浏览器验收通过（4.0 秒）。新增 PC 测试验证默认隐藏、整行悬停显示、移开隐藏、Tab 聚焦显示和 Enter 删除；手机测试验证常驻、44×44px 区域和 tap 删除。原有 AC-001—005 及存储异常测试通过。

桌面默认/悬停及手机截图已检查。首次尝试使用上次开发服务地址，因服务已停止而连接失败；改用 Playwright 自动启动服务器后全部通过。真实 CI 及生产构建结果见 PR Checks；合并后才发布。
