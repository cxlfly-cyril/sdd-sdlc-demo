# 弱化删除按钮

## 意图与规格影响

用户希望删除按钮更低调，同时手机上方便操作。分类为 visual；关联 AC-004、AC-005，业务规格不变。删除仍始终可见，键盘焦点和按 ID 删除逻辑保留。

方案：桌面删除文字由 12px 调整为 11px，中性灰色；取消红色悬停及浅红背景，鼠标悬停使用低调中性色。手机保留 12px 文字，所有设备点击区域至少 44×44px；触屏不应用鼠标 hover 效果。

## 验证

2026-10-10 本地：33 项单元测试、TypeScript 检查通过。4 项浏览器验收通过（3.3 秒），覆盖全部业务 AC 和存储降级。

1280×900 桌面、390×844 手机截图已查看；手机删除入口始终可见，点击区域至少 44×44px，无横向溢出。使用真正启用触控的 Chromium 上下文 tap 删除通过；桌面 Tab 到删除按钮时焦点轮廓可见，Enter 删除及刷新后不恢复通过。初次验证用程序 focus 未触发 focus-visible，改用实际 Tab 键后确认正常。

只改 CSS，不新增机械重复的样式测试。生产构建与新变更检查结果见本次 PR Checks；上线需用户合并 PR 后发布。
