# 监控方案

GitHub Actions 每 30 分钟检查固定 Pages 地址，也支持手动执行。检查 HTML、JS 和 CSS，最多重试 3 次；失败时记录 Issue 并使工作流失败。每次运行保留 JSON 证据 7 天。

用固定 HTML 标记识别监控事件，分页读取未关闭 Issue，排除 PR；同一监控串行运行。故障持续期间不重复建单或评论；恢复时记录证据并关闭。不会操作无标记的普通 Issue。

状态机和探针在单元测试中用伪 HTTP/API 验证。真实站点用 dry-run 只读检查。生产故障不用于本阶段测试；真实建单/恢复演练将在隔离故障阶段验证。

当前不接入 Agent 自动修复。由 GITHUB_TOKEN 创建的 Issue 不依赖其事件触发另一个工作流；后续采用显式触发链。
